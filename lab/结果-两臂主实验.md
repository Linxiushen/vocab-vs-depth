# 词表-深度权衡：两臂主实验结果（T=120M tokens, seed 42）

日期：2026-09-22。本文件只记录已经跑出来的数字与其适用边界，不做超出数据的推断。

## 两臂配置

两臂参数量对齐的方式是「把嵌入层省下/多花的参数用层数补偿」：A 用小词表多一层，B 用大词表少一层。

| | 臂 A | 臂 B |
|---|---|---|
| vocab_size | 6400 | 16384 |
| hidden_size | 768 | 768 |
| num_hidden_layers | 8 | 7 |
| 训练 token 数 | 120,000,000 | 120,000,000 |
| 更新步数 | 7339 | 7339 |
| tokens/update | 16,352 | 16,352 |
| 打包序列数 | 591,462 | 500,251 |
| 墙钟时长 | 17.4 h | 16.4 h |
| tokenizer sha256 | `cdd7e5bc16aa5081…` | `ff99beb3a8ea206d…` |

两臂 `packed_doc_order_sha256` 相同（`7d204f346dc15680…`），即看到的文档顺序一致，只有分词不同。

## 评测协议

`common_text_chunks_bos_per_chunk_v3`，`lab/eval_bpb.py --protocol v3`。两臂用同一份验证集与同一份 chunk 切分：

- `val_sha256` = `bac92439dfbad231…`（两臂相同）
- `chunks_sha256` = `51dc06f74152d687…`（两臂相同）
- 文档数 19,866，UTF-8 字节数 19,202,025（两臂相同）

用 bpb（bits per byte）而不是 perplexity 做主指标，因为两臂词表不同，token 数不可比：本次 A 消耗 4,795,627 token、B 消耗 4,052,414 token 去覆盖同样的字节。per-token 的 ppl 在这里没有跨臂意义（A=10.843 vs B=16.441，方向与 bpb 相反）。

## 主结果

| 指标 | 臂 A | 臂 B |
|---|---|---|
| bpb | 0.858790 | 0.852450 |
| loss (nats/token) | 2.383495 | 2.799804 |
| token 数 | 4,795,627 | 4,052,414 |
| ppl（不可跨臂比较） | 10.8427 | 16.4414 |

配对自举（`lab/power_analysis.py`，10000 次重采样，seed 0，两臂共用同一重采样索引）：

- bpb 差（A − B）= **0.006340**，正值表示 B 更好
- 标准误 = 0.000195
- 95% CI = [0.005959, 0.006716]，**不含 0**
- 相对 B 的幅度 = 0.744%

即：在 T=120M token、参数量对齐的前提下，**大词表少一层（B）优于小词表多一层（A）**，差距约 0.0063 bpb。

## 这个结论覆盖什么、不覆盖什么

- **覆盖**：这一份固定验证集上的测量噪声。95% CI 不含 0，且区间宽度（±0.000391）远小于效应量，所以「B 在这份验证集上更好」不是测量噪声。
- **不覆盖**：种子间的训练方差。每臂只训练了一个 seed（42），所以本实验**不能**排除「换个种子结论反转」。要支撑「大词表普遍更好」需要每臂多个种子重复训练。这一点在 `paired-armA-vs-armB.json` 的 `does_not_cover` 字段里也写着。
- **不覆盖**：其他 token 预算、其他模型规模、其他语料。T=120M 是一个很小的预算，词表大小的收益随预算变化是已知现象，本实验没有测这条曲线。
- 两臂的 bpb 都远好于随机初始化基线（`armA-random-eval-v3.json`，bpb 3.2103），说明两臂都确实学到了东西。

## 复现

```sh
# 臂 B 的 v3 评测（臂 A 同理，换 tokenizer/vocab_size/num_hidden_layers 与权重路径）
.venv/bin/python lab/eval_bpb.py \
    --weight lab/runs/pilot-B-s42-T120M/weights/pretrain_768_step0007339.pth \
    --tokenizer lab/tokenizers/bpe_16384 \
    --val lab/data/v3/val_large.jsonl \
    --vocab_size 16384 --hidden_size 768 --num_hidden_layers 7 \
    --max_seq_len 512 --protocol v3 --chunks lab/data/v3/eval_chunks_v3.jsonl \
    --seed 42 --output lab/results/armB-T120M-eval-v3.json

# 配对比较
.venv/bin/python lab/power_analysis.py \
    --a lab/results/armA-T120M-eval-v3.json \
    --b lab/results/armB-T120M-eval-v3.json \
    --resamples 10000 --seed 0 --out lab/results/paired-armA-vs-armB.json
```

权重 sha256：A `97b5d1dbf7c65994…`，B `72d55ddb25772711…`。权重不入库，单独发布在 Hugging Face。
